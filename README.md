# Chapters and Charms Games

1. Run `supabase-setup.sql` in Supabase SQL Editor.
2. Upload this entire folder (including `assets/`) to a GitHub repository.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)`.
4. Open the published root link. It is the host page. Use **Invite guests** to share the guest-only link.

The host’s private token is kept only in the host browser. The guest link never includes it, so guests cannot draw numbers. Claims are broadcast live to every player.
